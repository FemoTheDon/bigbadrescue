      Backups folder
      
          
      Every original is copied here before anything changes in Evernote, sorted by year and note.
      
        
      
        
      
          
          
          
        
      
      
      
      
      
        
      
          
      Pace
      
          
      Time between calls to Evernote. Slower is gentler on Evernote's limits. If Evernote asks for a pause anyway, BigBadRescue waits and carries on.
      
        
      
        
      
          
          
        
      
      
      
      
      
        
      
          
      Tag notes in Evernote
      
          
      Adds “BigBadRescue: converted” and “BigBadRescue: cleaned”, so you can search for them in Evernote.
      
        
      
        
      
      
      
      
        
      
          
      Trust the automatic check
      
          
      Skips the Review step: an MP3 that passed the automatic check counts as reviewed. Turn this on only after you've listened to a few.
      
        
      
        
      
      
      
      
        If sign-in fails
        
      BigBadRescue registers itself with Evernote when you first connect. If Evernote refuses that, you can enter a client ID that Evernote has issued, or the address of a client metadata document. Leave both empty normally.
